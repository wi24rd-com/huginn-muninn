# Getting help

Wi24rd Huginn and Muninn is a spare-time open source project with one maintainer. It comes without support: there is no help desk, no guaranteed answer and no response time. This page shows where to look and where to write.

## Look here first

- **The user guide:** [English](docs/manual/en/00-index.md) · [Dansk](docs/manual/da/00-index.md), also at [wi24rd.com](https://wi24rd.com/en/documentation/huginn-muninn/). It covers installation, the API Token at Cloudflare, every view, notifications, data, updating and uninstalling.
- **Troubleshooting:** [English](docs/manual/en/80-fejlfinding.md) · [Dansk](docs/manual/da/80-fejlfinding.md).
- **In the app:** the **?** at the top right explains the view you are in.

## Where to write

- **Something does not work, or you have a wish:** open an [issue](https://github.com/wi24rd-com/huginn-muninn/issues/new/choose). Search the existing issues first. If you do not use GitHub, write through the contact form on wi24rd.com: [English](https://wi24rd.com/en/contact/) · [Dansk](https://wi24rd.com/kontakt/).
- **A security problem:** privately, see [SECURITY.md](SECURITY.md).

Never paste your Cloudflare API Token, zone IDs or account IDs anywhere, and never the names of your domains on GitHub. If an API Token has been shown to others, delete it at Cloudflare and create a new one.

## What this project cannot help with

- Your Cloudflare account, plan, rules or settings: that is [Cloudflare's own support and documentation](https://developers.cloudflare.com/). The app only reads what Cloudflare reports.
- Advice on what to block or change for your particular site.
