# Tastaturgenveje

Genvejene står også i hjælpen (**?** øverst til højre) og i menuen **Vis** på macOS.

| Handling | macOS | Windows |
|---|---|---|
| Overblik | ⌘1 | Ctrl+1 |
| Siden sidst | ⌘2 | Ctrl+2 |
| Angreb | ⌘3 | Ctrl+3 |
| Robotter | ⌘4 | Ctrl+4 |
| Login | ⌘5 | Ctrl+5 |
| Dit land lige nu | ⌘6 | Ctrl+6 |
| Besøgende | ⌘7 | Ctrl+7 |
| Drift | ⌘8 | Ctrl+8 |
| Indstillinger | ⌘, | Ctrl+, |
| Hent nu | ⌘R | Ctrl+R eller F5 |
| Tilbage | ⌘[ eller ⌘← | Alt+← |
| Frem | ⌘] eller ⌘→ | Alt+→ |
| Større tekst | ⌘+ | Ctrl++ |
| Mindre tekst | ⌘− | Ctrl+− |
| Normal tekst | ⌘0 | Ctrl+0 |
| Luk hjælpen | Esc | Esc |
| Luk vinduet (programmet kører videre) | Det røde lukkeikon | Lukkeknappen |
| Afslut programmet helt | ⌘Q | **Afslut** i menuen i notifikationsområdet |
| Fuld skærm | Menuen **Vis** | – |

⌘← og ⌘→ virker ikke, mens markøren står i et tekstfelt; dér flytter de markøren.

## I visningerne

- **Tab** flytter mellem alt, der kan klikkes. **Enter** eller **mellemrum** åbner det valgte.
- En række i Overblik åbnes med **Enter**.
- **Kort og diagrammer** er ét Tab-stop hver: piletasterne flytter mellem landene, ringene og søjlerne, og Enter eller mellemrum åbner det valgte.
- **Teknologi pr. domæne**: tabellen er ét Tab-stop. Piletasterne flytter mellem cellerne, mellemrum skifter valg, og Enter går ind i gruppen, hvor piletasterne vælger, til Esc.
- **Klipning og indsætning** (⌘C, ⌘V) virker i API Token-feltet via menuen **Rediger**.
